## 🚀 Proyectos destacados

### 🎯 [Prep Entrevistas Técnicas](https://preparacion-entrevista-tech.onrender.com/#/home)
`Java` · `Spring Boot` · `JavaScript` · `WebAssembly`

Plataforma full-stack para practicar entrevistas técnicas (algoritmos, SQL y quizzes). Backend en Spring Boot (API REST, H2, JPA) y frontend en JavaScript vanilla. La ejecución de código ocurre 100% en el cliente: JavaScript dentro de un Web Worker aislado con timeout y SQL mediante sql.js (SQLite/WebAssembly), una decisión de arquitectura para evitar ejecutar código de usuario en el servidor, priorizando seguridad y costo de infraestructura.

### 💰 Gestor de Gastos
`Java` · `Spring Boot` · `JavaScript`

Aplicación full-stack de control de finanzas personales: ingresos y egresos, categorías personalizables, gastos fijos mensuales y metas de ahorro con seguimiento de aportes. API REST en Spring Boot (JPA/Hibernate, arquitectura en capas con DTOs y manejo centralizado de excepciones) y frontend en JavaScript vanilla con formularios tipo wizard y dashboard dinámico con gráficos por categoría.

### 🃏 [Sistema de Trivia y Perfiles](https://github.com/pacinimati/Juego-Preguntas-en-C)
`C`

Proyecto académico: motor de juego interactivo en C con algoritmos de bajo nivel y persistencia mediante archivos locales para perfiles, métricas de rendimiento e historial de partidas.
